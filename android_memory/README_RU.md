# V3.8 — заметки с явным согласием в контексте диалога

Продолжение V3.7, не новое приложение/иконка. Пользователь выбирает отдельные заметки галочками «Использовать в ответах ИИ». По умолчанию список пуст. Выбор хранится только в памяти процесса и сбрасывается после его завершения; удаление заметки снимает выбор. Лимиты: до 5 заметок, 3000 символов каждая и 6000 суммарно; текст не обрезается молча. Снимок выбранного списка берётся на главном потоке непосредственно перед голосовым запросом.

Выбранные заметки отправляются серверу и OpenAI вместе со следующим вопросом. Без выбора запрос имеет прежний формат. Снятие выбора прекращает повторное добавление заметки в новый контекст, но уже отправленные сведения могут сохраниться в ответах/истории разговора; это отражено в UI. Нельзя обещать удаление ранее переданного контекста.

Новый сервер принимает optional context_notes и memory_consent=true. Без явного boolean-согласия заметки отклоняются до вызова модели. Они передаются как справочные пользовательские данные, не повышаются до developer/system-инструкций, не записываются отдельно в MemoryStore и не представляются как история ChatGPT. История обычного разговора сохраняется как прежде.

Ветка V3.7 не содержала серверного UsageGate из отдельного PR #8. В V3.8 объединены существующие проверенные ограничения вызовов, включая учёт ошибок/таймаутов и HTTP429. Это лимит попыток, не денежная гарантия. Никаких дополнительных автоматических запросов нет: тот же один голосовой вопрос с выбранным контекстом.

Существующий сервер пользователя на VM использует /v1/lana/chat, а эта новая линия клиента — /v1/chat. Развёртывание, контракт старого backend и реальный API требуют отдельного этапа; совместимость с установленным backend пока не подтверждена. Никакие ключи не создавались, не менялись и не раскрывались. Samsung не обновлялся.

Проверки: локальный HTTP+SQLite+mock-модель проверяет согласие, отсутствие согласия, отзыв, границы, отсутствие отдельной записи заметок и сохранение платных квот. Android CI компилирует APK, затем на эмуляторе создаёт задачу/заметку, выбирает заметку, перезапускает процесс, проверяет сохранность записи и сброс согласия. Это раздельные backend/Android проверки, а не доказательство настоящего микрофона или модели.
