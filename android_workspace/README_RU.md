# LANA Live V3.7 — единое нативное рабочее пространство

Продолжение существующего приложения V3.6, не новый сайт. Та же Android package identity voicepreview; установленную Samsung-версию автоматически не меняем.

Добавлены Разговор / Задачи / Память / Команда / Настройки. Функции задач: добавить, отметить выполненной, вернуть в работу, удалить с подтверждением. Функции памяти: добавить подтверждённую заметку, прочитать, удалить с подтверждением. Записи сохраняются на планшете через отдельный SharedPreferences без изменения прежней истории/настроек. Повреждённые данные не перезаписываются; при ошибке сохранения нет сообщения об успехе. Лимиты: 100 задач и 100 заметок, 3000 символов в записи, точные дубли блокируются.

ВАЖНО: локальные заметки пока не попадают в серверный контекст модели. Это не подключение истории ChatGPT. Команда пока показывает честный статус неподключённых исполнителей. Автоматических API-вызовов, фонового прослушивания 24/7 и новых платежей эта работа не добавляет. Существующая голосовая логика и все поля серверного подключения сохранены, технические настройки перенесены из главного экрана в отдельный раздел.

Оформление — светлое тёплое с коралловыми акцентами. Утверждённое изображение Ланы отсутствует в старом Android ZIP и не заменяется выдуманным образом. Номер выбранного изображения в старых записях расходится (№3/№9), поэтому требуется восстановить сам оригинал; не считать финальный дизайн принятым.

Во время CI обнаружено: исходники stop/restart-guard ранее оставались локально и отсутствовали в удалённой V3.6-ветке. Недостающие LanaVoiceSession.kt, код генерации и native regression tests включены в PR #11. Прежний отчёт о полном сохранении этого исправления в PR #9 был неточен.

Локальная генерация сохраняет все прежние ID и исходный ZIP. GitHub Actions компилирует настоящий Kotlin и APK, затем выполняет на эмуляторе создание задачи/заметки, перезапуск, проверку сохранности, завершение и отмену удаления, переходы к настройкам и разговору. Сборка и фактические UI-тесты имеют отдельные статусы: успешная генерация исходников не считается готовым APK.

Следующее после прохождения CI: восстановить графический оригинал, согласовать серверный маршрут с существующим /v1/lana/chat на VM (сейчас клиент новой линии использует /v1/chat), передавать выбранную память с явным согласием, затем реальный Samsung и качество русского голоса. Не создавать новые серверные ключи: скрин 21.10 подтвердил наличие LANA_BACKEND_TOKEN и OPENAI_API_KEY в существующей .env на VM. Секреты не раскрывались.
