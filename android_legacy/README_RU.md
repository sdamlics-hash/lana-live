# V4.2 — совместимость с наблюдаемым существующим сервером

Контракт подтверждён тремя пользовательскими скринами SSH21.10: POST /v1/lana/chat; ChatRequest.message:str, history:list[Turn]; Turn.role:str/content:str; ChatResponse.reply:str. Схема чтения кода, а не доказательство живого OpenAI/HTTPS/авторизации. Прямого SSH-доступа этой сессии нет.

В настройках явный переключатель «Использовать существующий сервер Ланы», по умолчанию выключен для сохранения нового протокола. При включении клиент делает ровно один POST /v1/lana/chat с message/history и читает строго строковый reply. Новый режим сохраняет conversation_id/text, выбранные context_notes/memory_consent и answer. Нет автоматического перебора маршрутов/повторной POST-отправки. HTTPS/TLS и проверка сертификатов сохранены; redirects запрещены. Предположение Bearer-авторизации остаётся до реального теста; ключи не меняются.

История старого режима только в RAM текущего процесса: максимум16 сообщений и16000 символов, роли user/assistant. Отправляются лишь принятые успешные вопросы/ответы этого диалога. Контекст очищается при смене URL/токена/режима/диалога или перезапуске; старые запоздалые ответы не коммитятся до session guard. Исходная экранная история/прочие чаты автоматически не импортируются. Выбранные пользователем заметки включаются как справочные данные в message; без выбора их нет. Сырые заметки отдельно в RAM-историю не пишутся, но ответ может повторить сведения. Уже переданные сведения отзывом выбора не удаляются.

Поскольку серверные квоты старой VM пока не проверены, старый режим дополнительно ограничен на устройстве:30 попыток за час/100 за24ч. Попытка учитывается подтверждённым commit до сети, включая неудачи. Повреждённый счётчик или ошибка записи блокируют отправку. Это локальная квота приложения, не глобальная серверная/денежная гарантия; изменение часов/данных приложения и другие клиенты требуют серверной защиты. Автоматических запросов к модели для диагностики нет.

Устаревший сервер может не иметь /v1/connections. Такой ответ не подменяется зелёным статусом: состояние OpenAI и серверной памяти остаётся неподтверждённым. Даже валидный reply подтверждает серверный диалог, но не раскрывает провайдера/его режим. Доступ к истории ChatGPT не появляется.

Основа V4.1, versionCode7/versionName0.6.2-lana-legacy-contract. Сохранены release-ограничения: без явно заданного ключа выпуск блокируется. Новый debug APK — кандидат для теста, не безопасное обновление Samsung. Проблема разных подписей V3.9/V4.0 не считается решённой.

Проверки: генератор сохраняет прежний голос/память/статусы/защиту выпуска; Kotlin JUnit использует реальную JSON-библиотеку для точной схемы/ответов/отказа неверного reply, границ истории/ролей/изоляции и квоты. Эмулятор проверяет прежние записи и сохранение выбора старого режима после перезапуска. Микрофон/настоящий сервер/провайдер/HTTPS этими тестами не проверяются. VM и установленное приложение не меняются; API-ключи не создаются/не копируются.
