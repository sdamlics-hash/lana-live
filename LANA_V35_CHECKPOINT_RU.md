# Лана V3.5 — контрольная точка 21.10.2026

Статус: ТЕСТОВАЯ сборка Android + серверный код. Не установлена на планшет, не развёрнута на VM.

## Согласованные требования пользователя
- Отдельное приложение на Samsung, не браузерная вкладка.
- Активация голосом «Лана, ты тут?» и ответ «Да, я здесь! Слушаю тебя!».
- Один запуск голосового режима, затем автоматическое прослушивание следующего вопроса после ответа.
- Полноценные ответы через OpenAI, а не зашитые шаблоны.
- Память о разговорах, проектах, решениях; пока выполнена только ограниченная короткая история.
- Зрение экрана только после разрешения пользователя; старый модуль V3.3 сохранён без изменения.
- В будущем автономная серверная служба 24/7 для согласованных задач, отчетность и подтверждения для рискованных действий.

## Реализовано в этой ветке
1. Серверный POST /v1/chat под Bearer-токеном, с ограниченным размером запроса.
2. OpenAI Responses API через HTTPS, серверный OPENAI_API_KEY, store=false.
3. Короткая память в SQLite: 16 последних сообщений для одного conversation_id.
4. Android V3.5: SpeechRecognizer -> защищённый HTTPS endpoint -> TextToSpeech -> автоматическое возобновление распознавания.
5. После wake phrase следующие голосовые вопросы можно задавать без повторения имени Ланы (пока приложение активно).
6. Тестовое приложение имеет отдельный applicationId и может сосуществовать с основным.
7. Экран, платежи, брокерские ордера, отправка почты через серверный API не разрешены.

## Проверено
- GitHub Actions: тесты Python и Android patcher, компиляция Android APK и загрузка artifact.
- Тесты ИИ используют искусственный ответ (fake transport), без расходов API. **Живая переписка по OpenAI API на VM пока НЕ испытана.**
- Устройство Samsung, режим блокировки экрана, задержки TTS, реальный звук микрофона и суточная автономность требуют отдельных реальных тестов.

## Блокеры до первого разговора на планшете
- Серверное ядро намеренно слушает только 127.0.0.1; для планшета нужна защищённая HTTPS-точка через VPN/reverse proxy, привязанная к этому же API.
- На VM надо настроить OPENAI_API_KEY и LANA_API_TOKEN через защищённые переменные окружения, бюджет/ограничения и logs; никаких ключей в публичном GitHub.
- Bearer-токен в тестовом приложении хранится только в RAM и заново вводится после рестарта; постоянное хранение потребует Android Keystore.
- Нет проверенного постоянного фонового wake-word при выключенном экране. Android SpeechRecognizer работает в активном приложении и ограничен ОС.
- Открытые PR #2, #3, #4 — не сливать в main без проверки.

## Следующая программа работ
