# LANA: автономное ядро — экспериментальная версия

**Статус:** изолированный прототип, не установлен на сервере, не связан с приложением Ланы.

## Что реально работает

- Надёжная очередь SQLite, переживающая перезапуск процесса.
- Идемпотентность по ключу события: повторная постановка одной задачи не размножает работы.
- Журнал статусов и результатов (\`queued\`, \`claimed\`, \`completed\` / \`failed\`).
- Атомарное взятие задач одним воркером и повторное взятие при истекшей аренде.
- Оффлайн-проверка активности и отчёт по предоставленным **закрытым DEMO-сделкам**.
- Отчёт включает количество, долю выигрышей, net P/L и закрытую просадку.
- Тесты на повторные задачи, перезапуск, ошибки и запрет внешних действий.

## Чего здесь НЕТ

Нет подключения к OpenAI API, Gmail, Telegram, cTrader/FxPro, голосу или Android-приложению. Нет продакшен-запуска 24/7. Нет самостоятельного поиска контрагентов. Команда \`daemon\` лишь обрабатывает уже поставленные локальные задачи и сама ничего не планирует.

**Безопасность:** любые неподдерживаемые команды (отправка писем, реальные сделки, платежи, оболочка сервера) отклоняются. Никогда не класть API-ключи в репозиторий — он публичный.

## Локальный прогон

\`\`\`bash
python -m unittest discover -s tests -v
python -m lana_core.cli --db /tmp/lana.sqlite3 heartbeat
python -m lana_core.cli --db /tmp/lana.sqlite3 run-once
\`\`\`
