# Голос Shimmer в Android, V4.4

Реализован перенос серверного синтеза Shimmer 1,25× в нативный клиент. Это исходники и кандидат, не подтверждённая работа на Samsung.

Клиент делает один HTTPS POST /v1/lana/speech с Bearer токеном Ланы и текстом ответа. API-ключ OpenAI находится только на сервере. Запись ограничена 8МБ, redirects запрещены, действует обычная TLS-проверка. Временное аудио удаляется после ответа/остановки; результат прежнего сеанса не воспроизводится. После завершения — автоматическое слушание. Ошибка голоса сохраняет текст и показывается отдельно; автоматических повторных платных запросов нет. Системный Android TTS можно явно выбрать, выключив Shimmer в настройках.

Серверный адаптер server/lana_speech_router.py добавляется к существующему FastAPI app через app.include_router(create_router()). Он не заменяет chat endpoints. Требует существующие LANA_BACKEND_TOKEN и OPENAI_API_KEY в окружении процесса. /v1/lana/speech/status — только конфигурация, не проверка реального провайдера. Все маршруты требуют Bearer. До вызова провайдера SQLite атомарно считает попытку: 30/час,100/24ч, включая ошибки; одновременно один запрос. Это счёт запросов, не денежный лимит. Тексты и ключи в базе/ответах ошибок не сохраняются. Подключение к живой VM пока не выполнено; без него клиент покажет отсутствие маршрута. Не добавлять новый процесс/публичный порт/ключ в APK.
