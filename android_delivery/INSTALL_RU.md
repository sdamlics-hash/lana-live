# LANA 1057

Сохрани резервную копию данных приложения. Один раз установи LANA-OFFLINE-1057-TEST.apk поверх установленной Ланы. Нажми зелёную кнопку, чтобы проверить связь с каналом. Пока в канале 1057, ожидаемое сообщение — «Установлена актуальная версия».

Когда появится новая версия, кнопка загрузит её и откроет подтверждение Android. Удержание кнопки открывает ручной выбор APK для восстановления. Разговор и голос работают через локальные компоненты. Для проверки разговора отключи сеть и проверь пробу голоса, одну реплику и STOP на Samsung.

LANA-ROLLBACK-1058.apk возвращает код 1055 с прежней подписью. После отката для следующего обновления нужен APK выше 1058.
