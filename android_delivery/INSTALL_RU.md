# LANA 1059
На LANA 1057 нажми зелёную кнопку «Обновить LANA» и подтверди установку в Android. Затем скажи одну фразу. Если выбранного голоса нет, Лана использует доступный русский офлайн-голос Android. Проба выбранного голоса в настройках сохраняет его только после успешного завершения.
LANA-ROLLBACK-1060.apk возвращает код 1057 при необходимости. После отката следующий APK должен иметь версию выше 1060.
