# Разговор после неполной реплики

Основание: пользователь просит свободный разговор без повторных кнопок. В опубликованной 1029 обнаружено по коду: потерянное продолжение не отправляется модели, но завершает весь голосовой сеанс. Это безопасное отклонение неполного вопроса, однако неудобно для разговора.

Следующий кандидат сохраняет защиту от отправки обрезанной инструкции, но при первой/второй ошибке фразы даёт локальную голосовую просьбу повторить и возвращается к слушанию через существующий цикл завершения озвучки. Запрос модели не повторяется и не создаётся. После трёх неполных фраз подряд сеанс останавливается с объяснением, чтобы не зациклиться. Успешная целая реплика сбрасывает этот счётчик. Ошибки разрешения микрофона/языкового пакета по-прежнему останавливают сеанс. STOP и отмена сохраняют приоритет.

Локальная просьба повторить использует тот же сервис озвучки, что остальные локальные ответы. В режиме системного голоса это не вызывает сервер; при явном выборе облачного голоса существующий механизм синтеза может отправить запрос озвучки. Ни повторного вопроса модели, ни автоматического повтора платного запроса нет.

Из речевого текста перед TTS/облачным синтезом удаляются декоративные эмодзи, включая 😉: голос больше не получает этот символ для чтения как «подмигивание». Исходный ответ и эмодзи остаются на экране и в истории. Обычные слова, числа, суммы и математические знаки не изменяются; слово «подмигивание», если оно само было частью ответа, не удаляется.

Обычный Android no-match/timeout 6/7 больше не печатает сырую ошибку при каждом ожидании. Счётчики и отдельное сообщение ожидания сохраняются. Это снижение шума диагностики, не доказательство улучшения микрофона.

Локально: 116 Kotlin-тестов прошли. Дополнительные сценарии actual recognizer с имитацией Android callbacks проверяют неотправку префикса, голосовую просьбу повторить через callback и ограничение трёх неудач; они не проверяют реальный Samsung/звук. Требуются полная Android-сборка и эмулятор, затем фактическая проверка на устройстве. Нельзя обещать человеческую интонацию, бесшовный duplex или идентичность диалога ChatGPT по одним тестам.

Установленная пользователем версия подтверждена только 1028. 1029 опубликована, но установка ещё не подтверждена. Пакет, подпись, настройки, задачи и заметки сохраняются; приложение не удалять. Предпочтение внешности: забавный робот-персонаж, человеческий портрет пользователю не понравился; отдельное косметическое обновление сейчас не требуется.
