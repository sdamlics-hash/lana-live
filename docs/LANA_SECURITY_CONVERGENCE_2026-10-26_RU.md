# ЛАНА — серверная безопасность: план, журнал, точка продолжения (26.10.2026)

## Цель и критерии приёмки
Без изменения рабочей VM, телефона и основной ветки объединить в одном **черновом** кандидате две уже независимо испытанные защиты:
1. **Общий почасовой лимит** на платные вызовы модели (нельзя обойти сменой UUID разговора). Сохранить суточный и индивидуальный часовой лимиты, атомарность SQLite, восстановление после перезапуска и HTTP 429.
2. **Безопасный OpenAI HTTP-транспорт:** запретить любые HTTP-перенаправления, чтобы не передавать Authorization и текст беседы другому хосту; читать не более 1 MiB ответа; отвергать неверный JSON и неожиданную структуру, не печатать секреты.
3. **Независимая проверка:** полный Python CI, Android CI, регрессионные тесты на локальном HTTP-сервере. Не считать зелёный CI доказательством работающей VM/Samsung.
4. **Откат:** основная ветка и установленная APK не затронуты. Для отката достаточно не объединять черновой PR.

## Выполнение
- База: `fix/lana-https-response-bounds-20261025` (последний проверенный Android-кандидат PR #52).
- Перенесён общий лимит из чернового PR #17 (поверх защиты PR #8).
- Перенесён запрет редиректов и ограничение размера ответа из чернового PR #35.
- Сохранены более новые статусы соединений и согласованные контекстные заметки из актуальной ветки.
- Перенесены независимые регрессионные тесты обоих исправлений.
- Ветку `main`, рабочую VM, APK, GOLD и Kraken не менять.

## Ограничения
- **Лимит числа запросов — не лимит расходов в евро.** Дополнительно необходимы бюджет/мониторинг на стороне API и ограничение токенов.
- OpenAI-запросы в тестах идут только на локальный mock-сервер; реального платного запроса и доказательства подключения VM нет.
- Поскольку `SpeechRecognizer` по документации Android не рассчитан на непрерывное прослушивание, переход к wake-word требует отдельной подсистемы: локальный детектор ключевой фразы + пользовательский foreground-service с видимым уведомлением + измерение расхода батареи + явный STOP. При запуске из фона и после BOOT_COMPLETED действуют ограничения Android; обещать 24/7 нельзя.
- Не использовать сторонние модели wake-word без проверки лицензии и обработки аудио; сначала тест в эмуляторе, затем с разрешения пользователя на физическом Samsung.

## Журнал проверок
- До изменений: PR #52 — девять проверок GitHub Actions от 25.10.2026 успешно завершены.
- После изменений: **ожидается проверка GitHub Actions** (результат фиксировать только по логам).
- Точка продолжения: проверить Python тесты глобального лимита/редиректов, затем Android workflow; при ошибках исправить в этой ветке, максимум 5 циклов, затем пересмотреть подход.
- Оценка готовности не повышается автоматически: голосовая Лана ≈60%; автономная 24/7 ≈30% до живых испытаний.
