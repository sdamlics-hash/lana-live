# Лана — HTTPS/авторизация, контрольный этап 28.10.2026

## План и критерии
1. Проверить реальный TLS-handshake на локальном одноразовом сервере и отказ при недоверенном сертификате.
2. Отправить строго три **GET**: `/v1/status` без токена (ожидается 401), затем `/v1/status` и `/v1/connections` с отдельным токеном приложения.
3. Запретить HTTP, редиректы, токен в URL, неограниченные ответы и несовместимую схему.
4. Подтвердить по GitHub Actions все серверные тесты и совместимость Android-сборки.
5. Не выполнять POST, не вызывать OpenAI и не подключаться к реальной VM/Samsung.

## Выполнено в коде
- `staging/verify_https_auth.py`: только чтение, TLS-проверка системными сертификатами, 8-секундный тайм-аут, максимум 8192 байт на ответ.
- Без ключа ответ обязан быть HTTP 401; с ключом должны соответствовать обе JSON-схемы.
- Никакие исключения, сырые тела ответов, адреса или токены не попадают в диагностику.
- Серверные статусы `openai_api`, `chatgpt_history`, `lana_memory` считаются **утверждениями сервера**, а не доказательством реальной связи с поставщиком ИИ.
- Локальный TLS-тест генерирует одноразовый самоподписанный сертификат; без доверия соединение отвергается, при явном доверии проходит.
- Этот тест НЕ меняет доверенные сертификаты Android и не предлагает обход TLS-проверки.
- Ветка PR #10 содержит более ранний прототип HTTPS-проверки. Перед объединением понадобится выбрать один проверенный вариант, не оставлять дубликаты.

## Отдельно о фоновом голосе
Android 14+ требует `FOREGROUND_SERVICE_MICROPHONE`, `RECORD_AUDIO` и учёта ограничений запуска microphone foreground service из фона. Запуск из BOOT_COMPLETED не считать надёжным способом включить микрофон; планировать явный старт пользователем, видимое уведомление, остановку и локальную обработку ключевой фразы. Выбор движка wake-word, потребление батареи и работа при заблокированном экране требуют измерений на Samsung, а не имитации.

Официальные документы:
- https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start
- https://developer.android.com/develop/background-work/services/fgs/service-types
- https://developer.android.com/reference/android/speech/SpeechRecognizer
