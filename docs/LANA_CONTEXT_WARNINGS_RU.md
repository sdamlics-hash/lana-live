# Диагностика недоступного сохранённого контекста

В стабильной 1031 RuntimeTransport читает зашифрованную историю через LanaLegacyHistory, но не передаёт storageWarning в журнал. Ошибка сохранения проявляется после успешного ответа через contextSaved=false; если запрос отклонён локально или сеть не ответила, причина отсутствующего контекста не видна.

Теперь snapshot передаёт фиксированное локальное предупреждение диагностическому обработчику до проверки квоты и сетевого запроса. Сообщение видно в журнале сеанса обычного и фонового диалога; оно не озвучивается вместо ответа модели. После неудачного чтения новые принятые реплики продолжают использоваться в текущем сеансе, исходный файл не перезаписывается. Текст предупреждения уточнён именно для этого случая. Исключения диагностического обработчика не прерывают диалог. После успешного сохранения или смены области старое предупреждение больше не выдаётся.

Три регрессионных сценария проверяют исключение чтения без утечки его текста и без перезаписи, доступность новых реплик при сбое обработчика и смене области, ошибку записи с последующим восстановлением. Они не доказывают понимание темы моделью и не проверяют Samsung. Новых запросов, повторов, изменений ключей, подписи, формата хранилища и сервера нет.
