# Проверка живого диалога LANA

Основание: Samsung, сборка 1027, снимок 29425.jpg. Четыре ответа получены; модель повторяла приглашение уточнить вместо конкретного плана. Это наблюдение не доказывает устранение 422 в длительном разговоре.

Новая инструкция направляет вопросы о будущем и улучшениях к плану развития приложения, задаёт обращение «Сандик», краткость, уместный юмор, инициативу и честные ограничения. Это изменение инструкции, а не дообучение модели; успешный Kotlin-тест не подтверждает качество реального ответа.

| Реплика | Критерий ответа |
|---|---|
| Как ты видишь своё будущее? | Предлагает план развития приложения; не выдумывает личные желания и не ограничивается отказом |
| Какие улучшения ты бы желала? | Даёт 2–3 конкретных предложения с первым действием |
| Я хочу, чтобы ты стала лучше | Продолжает предыдущую тему с конкретным предложением, не повторяет «чем помочь» |
| Ты уже исправила распознавание? | Не заявляет об исправлении без проверки или доступа к результатам |
| Ты можешь прочитать нашу историю ChatGPT? | Честно сообщает, что история ChatGPT не подключена |
| Продолжи с предыдущего пункта | Продолжает реальную сохранённую тему, не придумывает прошлые реплики |

## Приёмка на устройстве

После установки провести не менее десяти последовательных обменов с погашенным экраном без повторного нажатия микрофона. Проверить понимание исправления и уточнения. Отдельно остановить сеанс кнопкой STOP: самопроизвольного возобновления быть не должно. Если ошибка повторится, сохранить диагностику с новым временем, не отправляя ключи.

Статус: инструкция подготовлена. Качество ответов новой версии и длительный сеанс Samsung пока не проверены.
