# LANA — приёмка голосового STOP и 25 последовательных обменов (01.11.2026)

## План и критерии
- Сохранить одну существующую Лану: не устанавливать новую APK на Samsung, не изменять VM, main и ключи.
- При произнесённом STOP немедленно инвалидировать текущую сессию: поздний ответ GPT/ASR/TTS не должен возобновить разговор. Остановить облачное воспроизведение; подтверждение STOP — только локальный Android TTS, без нового платного вызова.
- Проверить 25 последовательных русских HTTP-обменов через реальный **локальный** TLS/Bearer, ограниченную историю, одну ошибку модели и продолжение только по следующему явному вопросу.
- Все тесты CI должны пройти; до этого изменения — непроверенный кандидат.

## Изменения
- `android_speech/patch_v44.py`: после STOP обновляет ticket сессии, останавливает облачный плеер и текущий TTS, произносит подтверждение локальным TTS, затем остаётся в ожидании обращения. **Уже отправленный** серверу запрос не отменяется задним числом: счётчик попыток продолжает действовать.
- `android_speech/tests/test_stop_acceptance.py`: проверяет итоговый сгенерированный Android MainActivity (статическая проверка, не реальное аудио).
- `tests/test_https_chat_e2e.py`: 25 ответов через loopback TLS, проверка 20 пар контекста, отказ 503, неизменность SQLite при ошибке, 27 учитываемых попыток и явное продолжение без автоматического повтора.

## Проверка и честные границы
- GitHub Actions / Kotlin / эмулятор: результаты фиксировать после выполнения, а не по факту коммита.
- 25 ответов по тестовому TLS **не являются 20 минутами живой речи**. Модель имитируется; Samsung, микрофон, TTS, настоящий OpenAI и выключенный экран не задействованы.
- Не передавать в публичный GitHub API-ключи, приватные адреса, записи голоса, keystore или личную переписку.
- Подписанная APK возможна только после проверки packageName, увеличения versionCode и **совпадения SHA-256 сертификата с установленной Ланой**; debug-артефакт и успешный эмуляторный тест этого не доказывают.
- Прежде чем предлагать недельную DEMO-проверку, нужны независимые CI и безопасный staging с реальным HTTPS/GPT, затем согласованная проверка 20+ минут и 20+ обменов на Samsung с измерением задержек, STOP, повторного прослушивания и восстановления темы. Ни одной установки без согласования.
