# Лана — сквозная проверка HTTPS → авторизация → голосовой чат (30.10.2026)

## Цель
После PR #56, где проверялись только защищённые GET-маршруты, проверить **настоящий локальный TLS POST** через серверный маршрут разговора, без настоящего OpenAI и без доступа к устройству.

## План / критерии
1. Поднять одноразовый HTTPS-сервер **только на 127.0.0.1**, с временным самоподписанным сертификатом и отдельной SQLite-базой.
2. Доказать, что стандартное TLS-доверие отвергает сертификат, а явно доверенный тестовый сертификат разрешает обмен.
3. Оба голосовых POST-маршрута `/v1/chat` и `/v1/lana/chat` должны требовать Bearer; неправильный/отсутствующий токен — 401, **без вызова ИИ и без списания квоты**.
4. Проверить два последовательных русских запроса через реальный TLS, сохранение истории и подтверждённой памяти.
5. Запретить передачу выбранных заметок без явного `memory_consent=True`.
6. Проверить HTTP 429 при смене conversation_id после исчерпания глобального лимита и HTTP 403 для реальной торговли.
7. Все серверные тесты и связанные CI должны пройти. При ошибке — исправить и повторить.

## Что создано
`tests/test_https_chat_e2e.py`: 6 изолированных интеграционных тестов. Настоящие TCP/TLS, HTTP и SQLite; **поддельный транспорт модели**. Ни одна строка с настоящими ключами, адресами, историей пользователя или голосовыми данными не используется.

## Чего тест **не доказывает**
Ни настоящего HTTPS-домена/настроек VM, ни оплаченного OpenAI, ни работающего микрофона/женского TTS Samsung, ни корректного wake-word на заблокированном экране, ни 24/7. Самоподписанный тестовый сертификат **не** должен добавляться в доверенные сертификаты Android.

## Откат / точка продолжения
Откат — оставить отдельный draft PR неслитым, либо закрыть его после проверки. Main, сервер, установленная APK, GOLD и Kraken не меняются.
После CI следующий приоритет — подтверждённый защищённый staging с настоящим доверенным сертификатом и **отдельно согласованный** живой разговор на Samsung.

## Готовность
Голосовая Лана **≈60%**, полная автономная Лана 24/7 **≈30%**. Число тестов само по себе проценты не повышает.
