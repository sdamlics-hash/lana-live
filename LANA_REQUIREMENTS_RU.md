# ЛАНА — согласованные требования к единому приложению

## Главная цель
**Одна** постоянно доступная самостоятельная Лана, а не десятки тестовых APK.
Существующие тестовые приложения на Samsung оставляем нетронутыми до подтверждённой замены. Удалять старые версии автоматически нельзя.

## Голос и взаимодействие
- Отдельное Android-приложение, а не браузерная страница.
- Одна кнопка для запуска голосовой сессии; обращение «Лана, ты тут?» → «Да, я здесь!».
- После ответа автоматически снова слушать, без повторного нажатия и без повторения имени при продолжении беседы.
- Состояния: «Слушаю», «Думаю», «Отвечаю», «Ошибка соединения».
- Русский живой диалог на уровне языковой модели, не шаблонный бот; русская речь и приятный стабильный голос.
- Фоновая работа, когда экран выключен: **отдельный блок работ**, Android требует осознанных разрешений и foreground service. Не заявлять готовность по эмуляторной проверке экрана.

## Зрение, память и поведение
- При явном разрешении видит экран, умеет оценивать кадры; не слать снимки без согласия.
- Хранит важные факты о проектах, предпочтениях и договорённостях в отдельной долговременной памяти; контекст ChatGPT автоматически НЕ доступен.
- Говорит правду о выполненном, не выдумывает запуск процессов, возможности и доступ.
- Естественный тон, уместный юмор. Может обоснованно не соглашаться.
- Действия с деньгами, реальным трейдингом, юридическими документами, удалением данных — только после одобрения.

## Автономные задачи
- GOLD и Kraken: вначале только чтение логов, анализ закрытых DEMO-сделок, тесты; реальную торговлю не включать.
- Брокер: поиск реальных соответствий покупатель/продавец, аккуратная проверка фактов, переписка лишь в заранее предоставленных полномочиях.
- Тестирование кода, аккуратные изолированные ветки, журналы, уведомления о результате.
- Отказоустойчивый сервер, периодические проверки и автоматическое возобновление после сбоя.
- Планирование и инструменты — **пока НЕ реализованы в V3.5**, их не подменяет сам разговор с OpenAI.

## Путь к одному установленному приложению
1. Испытать серверное ядро и чат в тестовой среде, без доступа к живой торговле.
2. Проверить эмулятор, затем голос и сеть на реальном устройстве Samsung.
3. Проверить безопасность, наличие сетевых лимитов, разрешений, бэкап памяти и стабильность.
4. Подписать финальный APK стабильным ключом; определить способ обновления текущего пакета без потери данных.
5. После подтверждения — перейти на одно приложение, старые TEST-версии удалить только по явному решению пользователя.

## Текущее состояние
V3.5: сборка APK, установка на эмулятор и отображение интерфейса прошли тест. Реальный живой доступ к OpenAI API на сервере, звук на Samsung, фоновые сервисы и круглосуточное выполнение пока не проверены.

## Уточнение состояния — 23.10.2026, после сборки 1027

Исторический раздел V3.5 выше не описывает текущую версию. Текущий пакет ai.dreibus.lanalive.stablevoice; имя LANA, локальный отклик «Да, Сантик.» по прямому пожеланию пользователя. Подпись обновлений сохраняется, приложение не удаляем.

На Samsung пользователь подтвердил несколько озвученных связанных ответов с погашенным экраном на 1026. Затем повторялась HTTP 422. Проверка схемы на dreibus-bot показала maxItems=12 для history и maxLength=4000 для message/content; клиент исправлен в опубликованной 1027. Установку 1027 пользователь показал на скрине. Длительный разговор после исправления и отсутствие ошибок на десяти обменах ещё не подтверждены. На последнем снимке четыре обычных ответа есть, но они повторяют уточняющие вопросы вместо предложений.

Следующий блок: конкретные инициативные предложения, сохранение темы, живой краткий тон без выдуманных возможностей. Изменение инструкции само по себе не подтверждает качество ответов: нужна проверка по сценариям docs/LANA_DIALOGUE_ACCEPTANCE_RU.md. Микрофон и озвучка принадлежат Android-сервису; явный STOP обязателен. Геолокация и подключение истории текущего ChatGPT не реализованы, Claude/Manus не подключены. Ни CI, ни отдельный удачный диалог не доказывают режим 24/7.
