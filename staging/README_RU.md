# Лана — подготовка автозапуска на сервере (staging)

Статус: исходники двух безопасных systemd-служб, **не установлены** на VM пользователя и не запущены. Это только тестовая заготовка для отдельного сервера.

Службы:
- `lana-core-api.service`: локальный HTTP интерфейс только на `127.0.0.1:8787`, авторизация токеном, режим ограниченных операций. Это **не** публичный веб-сервер.
- `lana-core-worker.service`: обрабатывает локальную очередь задач из SQLite, не имеет доступа к сети (`PrivateNetwork=true`) и не получает ключ OpenAI.
- Обе автоматически восстанавливаются после падения процесса благодаря `Restart=always`.
- Используется единая база `/var/lib/lana/lana.sqlite3`, отдельный пользователь `lana`, ограниченная файловая система и системные привилегии.

## Проверка до развёртывания

```bash
python3 -m unittest discover -s staging/tests -v
python3 -m unittest discover -s tests -v
python3 staging/preflight.py
```

Последняя команда печатает лишь наличие или отсутствие обязательных условий, **не значения секретов**. Без безопасно заданных `LANA_API_TOKEN` и `OPENAI_API_KEY` она обязана отказать, а не утверждать готовность.

## Что нужно сделать позже, получив безопасный доступ и разрешение

1. Проверить ОС, загрузку процессора, диска и RAM рабочей VM, не затронув GOLD и Kraken.
2. Подготовить отдельную площадку для тестовой Ланы: код под `/opt/lana`, системный пользователь `lana`, SQLite под `/var/lib/lana`.
3. Сгенерировать секреты **непосредственно на сервере**, установить конфигурационный файл `/etc/lana/lana.env` с правами root:0600. Ключи никогда не пересылать в чат, не загружать на GitHub и не встраивать в APK.
4. Провести системную проверку unit-файлов, тесты сетевого API, systemd, restart/recovery, контроль журналов и ограничений памяти.
5. Подключить планшет по проверенному TLS/VPN к отдельному шлюзу и только после этого тестировать реальный русский голос и OpenAI.
6. Дальше постепенно подключать мониторинг роботов только для чтения и с журналом действий.

**Запреты:** никакого прямого открытия порта 8787 в интернет; никаких платежей, реальных торговых ордеров, автоматической установки на Samsung или удаления старых APK. Без завершённого суточного теста нельзя считать автономную Лану работающей 24/7.
