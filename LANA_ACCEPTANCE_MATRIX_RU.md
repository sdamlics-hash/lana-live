# ЛАНА — матрица готовности по нашим договорённостям

Этот документ фиксирует наши прежние разговоры и разобранные идеи для Ланы, чтобы не потерять их при следующих доработках. Часть старых видеофайлов недоступна для повторной покадровой проверки; **это перечень требований из бесед, а не дословная расшифровка видео**.

| Функция | Требование | Состояние и критерий приёмки |
|---|---|---|
| Настоящее приложение | ОДНА самостоятельная Android APK на Samsung, без Chrome | APK V3.5 проверен на Android-эмуляторе; на Samsung ещё не тестировался. Не создавать новые иконки без решения пользователя |
| Голос-пуск | «Лана, ты тут?» → «Да, я здесь!» | Реализована логика и распознаватель Android. Проверять реальным микрофоном после серверного подключения |
| Без кнопок после ответа | Автоматически снова слушает, следующий вопрос без повторения имени | Исправлен голосовой маршрут и очередность STOP/WAKE в V3.6; необходима проверка живого аудио |
| Стоп | «Лана, хватит», «Лана, стоп», «стоп разговор», кнопка | В V3.6 фразы STOP имеют приоритет; отменяются отложенные повторные запуски микрофона |
| Качество речи | Живой русский женский голос, приятный, стабильный от начала до конца, без инородного акцента | Сейчас используется встроенный Android TTS; качество не подтверждено, требуется сравнение с серверным голосом/потоковым воспроизведением |
| Умный разговор | Уровень полноценной языковой модели, не жёсткие шаблоны | Есть серверный вызов OpenAI в тестовой ветке, с имитированными ответами в тестах; реальный API на VM не включён |
| Статусы | «Слушаю / Думаю / Отвечаю» с честными ошибками | Есть базовые статусы в Android; требуется проверка на устройстве |
| Память | История разговора, подтверждённые долговременные предпочтения, память по работе/проектам; не придумывать доступ к ChatGPT-истории | SQLite короткой истории и отдельная одобренная память готовы как код. Долговременное восстановление после сбоя VM ещё не испытано |
| Зрение | По разрешению видеть экран/камеру, обсуждать то, что видно, без скрытого сбора данных | Старый MediaProjection умеет делать JPEG каждые 3 секунды; **без авторизованного канала и ИИ-обработчика не считать зрение работающим** |
| Внешность | Выбранный робот-женщина №9, полный рост, светлая композиция, яркие зелёные листья конопли, не чёрно-синий экран | Требование к финальному UI. Текущий APK — технический прототип, дизайн не принят |
| Самостоятельность | Работать 24/7, самостоятельно выполнять согласованные задачи и приходить с результатами/вопросами по существенным решениям | Очередь задач и шаблоны перезапуска созданы; на сервере пользователя ещё не развернуты и суточный тест не проведён |
| Работа с GOLD/Kraken | Проверять логи и улучшения, DEMO, не ломать существующие боты, реальные деньги только с подтверждением | Рабочие боты не подключены; включать только при безопасной изоляции |
| Брокерские дела | Искать реальные пары покупатель/продавец, вести разрешённую переписку, проверять факты, не дублировать письма | Нет подтверждённого подключения инструментов в приложении Ланы |
| Сохранность | APK из исходников, резервные копии, разделение проектов и проверка перед установкой; не просить ставить каждую тестовую версию | Разработка только в черновых PR; старая установленная версия не изменялась |
| Живой голос и эмоции | Пользователь не хочет вялый, монотонный TTS и задержки; интерфейс должен быстро реагировать | Нужны измерения латентности, проверка женских русских голосов; не заявлять выполненным до теста |
| Безопасное обучение | Лана аргументированно возражает, честно сообщает, что сделано/не сделано; опасные изменения — с разрешения | Включено в серверную инструкцию как правило, выполнение в живых условиях не проверялось |

## Последовательность испытаний до предложения установки

1. **Автоматические тесты:** корректная обработка голосовых команд, Kotlin JUnit, сборка APK, запуск на Android-эмуляторе, серверные регрессии.
2. **Сервер:** изолированная VM, настоящий OpenAI API без секретов в APK, TLS/VPN, контроль стоимости, журнал ошибок и восстановление.
3. **Реальный Samsung:** проверить микрофон, русский голос, wake-word, стоп, беседу 20+ минут, сеть, память, смену ориентации и возврат в приложение.
4. **Фон:** отдельно проверять блокировку экрана и разрешения Android; не обещать круглосуточное скрытое прослушивание или работу без системных ограничений.
5. **Одна итоговая APK:** заменить/убрать старые TEST-варианты по решению пользователя; не предлагать ставить каждую промежуточную сборку.

Прогресс проверять по фактам и логам, не по числу созданных APK.
