# V3.9 — честные статусы и явный маршрут диалога

Продолжает V3.8, сохраняя приложение, голосовые guards, задачи, локальную память, согласие на отправку заметок и настройки. В настройках есть постоянная панель из трёх статусов. Нажатие существующей кнопки связи запрашивает только GET /v1/connections: без вызова модели, создания заданий и расхода квоты API.

OpenAI: отсутствие ключа — не настроен; наличие ключа без успешного ответа — не проверен; mock-транспорт всегда тестовый режим. Только непустой успешный ответ реального транспорта даёт «подключён», свидетельство действует пять минут в рамках процесса. Ошибка последнего вызова снимает подтверждение; перезапуск очищает свидетельство. Диагностика не является новым API-запросом и не доказывает будущую доступность.

История ChatGPT: не подключена. Неизвестное значение от сервера не принимается как подтверждение. Серверная память: реальный SELECT проверяет чтение таблицы approved_memory; статус явно говорит, что запись не проверена. Тексты памяти, ключи, пути и сообщения провайдера не выдаются диагностикой. Локальные заметки планшета — отдельное хранилище с проверкой успешного сохранения в V3.7/V3.8.

Новый backend принимает /v1/chat и /v1/lana/chat с одним и тем же строгим контрактом conversation_id,text и теми же auth/consent/quota. Android принимает корень HTTPS или полный адрес одного из этих маршрутов. Никакой автоматической повторной POST-отправки на другой маршрут нет. Префикс reverse proxy сохраняется. TLS/проверка сертификатов не отключается; redirects запрещены.

Это НЕ доказательство совместимости с действующим старым ~/lana_backend/project/backend/lana_api.py. Его маршрут /v1/lana/chat известен, формат запроса/ответа — ещё нет. Не менять сервер/ключи вслепую. Сервер, не поддерживающий диагностику, получает статус «не подтверждено». Ничего не установлено на Samsung и не развёрнуто на VM.

Проверки: реальный локальный HTTP и SQLite, mock транспорта без сети: авторизация, отсутствие ключа, ключ без запроса, mock вместо OpenAI, успешный ответ/истечение свидетельства/ошибка, ошибка памяти, отсутствие утечки, оба маршрута и отказ от неизвестной legacy-схемы. CI: Kotlin JUnit проверяет фактические правила статусов и URL; APK+эмулятор — статусы до проверки, сохранность задач/заметок и сброс выбора. Настоящий микрофон и платный OpenAI этими тестами не проверяются.
